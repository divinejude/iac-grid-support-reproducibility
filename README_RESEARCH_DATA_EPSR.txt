EPSR reproducibility and research-data package

This archive contains the code, OpenDSS feeder files, consistency/trackability-check scripts,
derived calibration outputs, experiment summaries, manuscript figures/tables,
representative full-suite traces used by the default check scripts, and
execution metadata needed to reproduce the reported simulations.

Included material:

- iac_dmpc/: Python package for the IAC plant, inverter constraints, feeder
  approximation, network-aware fleet MPC controller, signal processing,
  metrics, and plotting.
- examples/: OpenDSS IEEE 13-node feeder files and example feeder models.
- tests/: regression tests for calibration, feeder/co-simulation, converter
  trackability checks, transient-stability checks, and physical model checks.
- run_experiment_suite.py: deterministic and uncertainty experiment runner.
- summarize_experiments.py: summary-table and figure aggregation script.
- calibrate_from_nist_nzertf.py: measured-data thermal calibration workflow.
- calibrate_from_resstock.py: ResStock/EnergyPlus calibration workflow.
- validate_*.py: ANDES frequency, T&D consistency, and averaged/switching
  converter trackability-check scripts.
- data/: lightweight derived calibration parameters, processed calibration
  time series, and dynamic replay traces.
- paper_outputs*/: generated result CSV summaries and diagnostic figures.
- experiments/nist_measured_calibrated/full/: compact representative full-suite
  subset containing the voltage-sag and feeder-stress traces required by the
  default check and paper-asset commands, plus the full metrics summary.
- paper/: figure/table generation scripts used for the manuscript.

Excluded material:

Large raw public datasets are not duplicated in this archive. The NIST NZERTF
measured data and ResStock/EnergyPlus outputs are public datasets and are
retrieved or queried by the calibration scripts. Complete full-suite per-case
experiment folders are regenerated by the experiment runner; paper-ready
summary outputs and the representative traces needed by the default check
commands are included.

Typical reproduction workflow:

The bundled CSV, JSON, figure, and table outputs are frozen precomputed results
from the reported study. Reviewers can inspect them without rerunning the full
suite. The smoke-test workflow below is the recommended first executable check;
the complete suite is substantially more computationally expensive because it
solves repeated feeder power flows and MPC problems across all scenarios.

1. Install Python dependencies:
   pip install -r requirements.txt
   pip install -r requirements-validation.txt

2. Re-run measured-data calibration:
   python calibrate_from_nist_nzertf.py

3. Regenerate or refresh the dynamic frequency replay trace:
   python generate_dynamic_frequency_trace.py

4. Run a fast reviewer smoke test:
   python -m pytest tests
   python run_experiment_suite.py --scenario-set quick --thermal-calibration-json data/nist_nzertf/calibrated_thermal_parameters.json --output-dir experiments/reviewer_quick_check
   python summarize_experiments.py --experiment-dir experiments/reviewer_quick_check/quick --output-dir paper_outputs_reviewer_quick

5. Re-run the complete main experiment suite:
   python run_experiment_suite.py --scenario-set full --thermal-calibration-json data/nist_nzertf/calibrated_thermal_parameters.json --output-dir experiments/nist_measured_calibrated
   python run_experiment_suite.py --scenario-set monte_carlo --thermal-calibration-json data/nist_nzertf/calibrated_thermal_parameters.json --output-dir experiments/nist_measured_calibrated

   The scenario-set name monte_carlo is retained for command-line
   reproducibility. The bundled three-case NIST-calibrated output is a limited
   stochastic diagnostic for noise, delay, compressor-time, sampled fleet size,
   and sag settings, not statistical Monte Carlo robustness evidence.

6. Summarize experiments:
   python summarize_experiments.py --experiment-dir experiments/nist_measured_calibrated/full --experiment-dir experiments/nist_measured_calibrated/monte_carlo --output-dir paper_outputs_nist_measured_calibrated

7. Regenerate manuscript assets:
   python paper/generate_paper_assets.py

   This writes the public-package figures and tables under paper/.

8. Inspect the frozen shared-headroom mechanism ablation:
   python analyze_headroom_tradeoff.py

   The script reuses the bundled trajectories when present and regenerates the
   summary table and figure without rerunning those cases.

9. Run the public-package preflight from the extracted archive root:
   python scripts/package_preflight.py --public-package .

The manuscript assembly tree, submission packaging scripts, and manuscript
asset-synchronization utility are authoring-only and intentionally excluded.
They are unnecessary for inspecting or reproducing the public computational
results.

On some Windows/OpenDSS installations, opendssdirect may print a backend
shutdown stack trace after pytest has already reported success. The run is
considered successful when pytest reports all tests passed and returns exit
code 0.

The public NIST NZERTF measured dataset used for thermal calibration is
available from NIST. The submitted manuscript cites the dataset source and DOI.

Scope limitations:

- The OpenDSS feeder study is quasi-static RMS simulation, not EMT or hardware
  validation.
- ANDES checks the active-power/frequency channel; the explicit T&D workflow is
  a loose-coupled consistency check.
- Averaged and switching inverter studies are representative converter
  trackability checks, not laboratory or field validation.
- The bundled three-case `monte_carlo` output is a limited stochastic
  diagnostic, not statistical robustness evidence.
